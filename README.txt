Maze Chomp - Android project (WebView wrapper) by Hamza Bin Masood

BUILD THE APK
1. Install Android Studio (free): https://developer.android.com/studio
2. File > Open > select this MazeChomp-Android folder. Let Gradle sync finish.
3. Test: plug in your phone (USB debugging on) or start an emulator, press Run.
4. Share/install an APK: Build > Build APK(s). The file appears in app/build/outputs/apk/debug/
   Copy app-debug.apk to your phone and open it (allow "install unknown apps").
5. For Google Play: Build > Generate Signed App Bundle / APK.

The game itself lives in app/src/main/assets/index.html.

NO ANDROID STUDIO? BUILD THE APK ONLINE FOR FREE (GitHub)
1. Create a free account at https://github.com and make a new repository.
2. Upload ALL files of this folder (including the hidden .github folder) to the repository.
3. Open the "Actions" tab > "Build APK" > wait ~3-5 minutes for the green check.
4. Open the finished run > Artifacts > download "MazeChomp-APK" (zip containing app-debug.apk).
5. Send app-debug.apk to your phone and install it.
